・アプリ全体：290問（CPA教材対応123問 + 解法マスター167問）

PDFの問題と解答を参照して、論点と解法を踏まえたオリジナル問題を作っています。
出版社の原問題を転載したものではありません。元の教材の数値とは異なるので、
解答PDFに記載される数値とアプリの数値は一致しません。
同梱の「問題対応表.csv」で問題ID・元の問題PDFページ・解答PDF参照ページを確認できます。

■ GitHub Pages 更新
1. 更新前にアプリ画面から学習記録をJSONバックアップする。
2. ZIPを展開し、中のファイルとiconsフォルダをGitHubリポジトリのルートに上書きする。
3. Commit changes を押し、数分待って既存のPWAを再起動する。
4. GitHub Pages の Settings は通常変更不要。
5. 元の問題PDF・解答PDFは著作物です。このZIPには含まれておらず、GitHubへ公開しないでください。

■ 学習履歴
CPA教材の既存問題IDは維持しました。
旧Ver.10の解法マスター理論問題は内容が変わったため、誤った成績を
新しい計算問題に引き継がないようM11-S/Gから始まる新IDにしています。

■ 品質と免責
自動検査でページの網羅・問題の重複・選択肢の重複・正答値と解説の整合性を確認しています。
試験の公式解答と異なる独自設定の問題です。すべてについて第三者の専門家による
校閲や最新の会計基準・出題範囲との全面照合を済ませたものではありません。
