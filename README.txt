簿記1級 通勤TRAINING - PWA版

【実装済み】
1. 学習履歴の保存（IndexedDB）
2. 論点別学習（商業簿記・会計学／工業簿記・原価計算を細分化）
3. 計算問題・仕訳問題
4. 苦手問題の優先出題（正答率、直近ミス、復習期日から自動判定）
5. PWA対応（ホーム画面追加、オフラインキャッシュ）

【スマホで使う方法】
PWAのインストールには、原則としてHTTPSでこのフォルダを公開する必要があります。
GitHub Pages / Cloudflare Pages / Netlify などの静的ホスティングに、このフォルダの中身をアップロードしてください。
公開URLをChromeで開き、「ホーム画面に追加」または「インストール」を選択します。

【ローカルPCで動作確認】
このフォルダで簡易HTTPサーバーを起動します。
例: python -m http.server 8000
その後 http://localhost:8000 を開いてください。

【学習データ】
履歴・お気に入り・苦手情報はブラウザ内のIndexedDBに保存されます。
ブラウザのサイトデータを削除すると履歴も消えます。
