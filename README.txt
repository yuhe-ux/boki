【大事な注意】
教材の該当論点と章を参照してオリジナルで作成した演習問題です。教材本文・例題の転載ではありません。
今回の99問は各書籍の章・説明と照らして独自作成していますが、最新の検定改正の全項目との照合や
全ページからの網羅的な問題化は完了していません。付与していない重要度は「未設定」と表示します。
教科書は2023年刊行であり、試験範囲や会計基準に関する最新の変更は日本商工会議所等で確認してください。
参照先「PDFページ」は、PDFビューアに表示される1始まりのページ番号です。
既存の第Ⅰ部36問は、書籍本文に印字されたページ番号です（出典表示で区別）。
講義レジュメは一部画像PDFを目視で確認しています。

【公開・更新】
このフォルダ内のファイルとiconsフォルダをGitHub Pagesのリポジトリのルートに上書きアップロード。
PDF教材そのものはGitHubにアップロードしないでください。
index.html、app.js、questions-cpa-part1.js、questions-cpa-all.js、styles.css、
service-worker.js、manifest.webmanifest、icons/ がルートに配置されている必要があります。
GitHub Pagesで反映後、Webブラウザの再読み込みで更新。ホーム画面アプリはそのまま使えます。

【学習記録】
旧版とIndexedDBの同じ DB_NAME=boki1_commute_db / object store=kv / key=state を使用。
同じURL・同じブラウザなら学習履歴の保持を意図しています。
ただしブラウザのサイトデータ削除やURL変更により失われる場合があるため、
学習記録のバックアップ機能を併用してください。

【iPhone】Safariで公開済みアプリを開き、共有ボタン→ホーム画面に追加。
【Android】Chromeで開き、メニュー→ホーム画面に追加/インストール。
