簿記1級 通勤TRAINING Ver.7（電卓の3桁カンマ表示対応）

■ 変更点
・電卓の入力途中と計算結果を3桁ごとにカンマ区切りで表示します。
  例：1234567 → 1,234,567 / 1200.50 → 1,200.50
・演算に使う数値はカンマを含まないため、四則演算・小数・括弧・％・1文字削除は従来どおり使えます。
・問題数や出題内容・学習履歴データベースはVer.6から変更していません。

■ GitHub Pages 更新手順
・このZIPの中身を既存リポジトリのルートに上書きアップロードしてください。
・index.html, app.js, service-worker.js が特に重要です（他のファイルも同梱しています）。
・PagesのSettingsは変更不要です。
・端末に旧画面が残る場合は、サイト更新完了後にアプリを閉じて再起動してください。
・データの保護のため、Chrome/Safariのサイトデータの削除は避けてください。

■ 学習履歴と出典について
・既存の有効な問題IDは変更していないため、同じURL・同じ端末のIndexedDBから成績を引き継ぎます。
・削除した問題IDは出題・成績の対象外です。復元バックアップ内に保存された記録は移行時に非表示にされます。
・教材の計算方式や論点を基にした独自問題であり、著作物の設問を転載していません。
・商会Ⅰ〜Ⅲ部、工原Ⅰ〜Ⅱ部、講義レジュメ6ファイルを参照しています。
・重要度欄に「未設定」の問題はCPA教材のA/B/C評価を独自推測していません。
・改正会計基準と最新出題範囲の全面照合は別途必要です。
